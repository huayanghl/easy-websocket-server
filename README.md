# 🌐 ws-node

> 去中心化 WebSocket 公共节点网络 —— 任何人都可以部署节点，任何人都可以免费使用

---

## ✨ 特性

- 单节点支持 10000+ 人同时在线
- 每个客户端用 60 位 ID 作为唯一身份，客户端本地生成，无需注册
- 点对点发送消息、群发广播
- 对方不在线时自动存离线消息，上线后自动推送
- 任何人都可以部署公共节点，互相补充，无需中心化授权
- 日志自动写入 `logs/server.log`
- 支持 WSS 加密（可选）
- IP 限流、防攻击

## 📱 客户端如何接入

**第一步：搞一个 60 位的 ID**

你自己在本地随便生成一个 60 位的字符串就行，用数字加字母混合，想怎么编都行，这就是你的唯一身份标识，不用找谁申请。

**第二步：挑一个节点连上去**

从上面的公共节点列表里随便挑一个地址，用 WebSocket 连上去，连上之后立刻把你的 60 位 ID 发过去注册一下，就算登录成功了。

**第三步：找别人聊天**

想跟谁说话，就指定对方的 60 位 ID，然后把你的消息发过去，服务器会自动帮你转达。

**第四步：收消息**

别人发你的消息你会实时收到。如果你不在线，别人发的消息服务器会帮你存着，等你上线了一次性全推给你。

**第五步：看谁在**

你随时可以问服务器要在线名单，服务器会把所有在线的 60 位 ID 告诉你。

## 📖 客户端示例

本项目提供了两种语言的客户端示例，直接打开或运行即可使用：

| 文件 | 说明 | 运行方式 |
|------|------|----------|
| `example.html` | 浏览器客户端（带界面） | 双击用浏览器打开 |
| `example.php` | PHP 命令行客户端 | 终端执行 |

**如果你需要其他语言的客户端（Python、Java、Go、Rust 等）**，直接把 `example.html` 或 `example.php` 丢给 AI，让它帮你翻译成目标语言即可。

**如果你想深度定制客户端行为**，把 `server.js` 丢给 AI，让它根据你的需求调整协议。

## 📡 通信协议

**客户端可以发送的指令：**

| 指令 | 说明 |
|------|------|
| `register` | 把你的 60 位 ID 告诉服务器 |
| `send` | 指定对方 ID 和消息内容，发送私聊消息 |
| `broadcast` | 发一条所有人能收到的消息 |
| `get_online` | 问服务器谁在线 |

**服务器会推送的消息：**

| 消息 | 说明 |
|------|------|
| `registered` | 注册成功，告诉你当前多少人在线 |
| `message` | 别人发给你的私聊消息 |
| `broadcast` | 别人群发的广播消息 |
| `offline_message` | 你不在线时别人发给你的消息 |
| `online_list` | 你问在线名单时服务器返回的列表 |

不会部署的话，把 `server.js` 丢给 AI，告诉它你要部署到什么地方（云服务器、树莓派、内网穿透等），AI 会告诉你怎么做。

**第二步：Fork 本仓库**

**第三步：修改 README.md 里的公共节点列表，加上你的节点信息**

**第四步：提交 Pull Request**

**第五步：等合并后，大家就都能看到你的节点了**
